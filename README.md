# 项目经历展示

这是一个可直接发布到 GitHub Pages 的纯前端作品集页面，用来展示四个设计项目：

- 宠物心跳检测仪
- 智能小提琴
- 桌面神龛
- 陶瓷酒器创意设计

页面采用单文件 `index.html` 实现，所有项目图片按文件夹相对路径加载，支持点击图片展开全图查看。

## 预览方式

直接在浏览器中打开 `index.html` 即可查看。

如果想用本地静态服务预览，也可以在项目根目录执行任意静态服务器，例如：

```bash
npx serve .
```

然后打开终端提示的本地地址。

## 发布到 GitHub Pages

1. 将整个项目推送到 GitHub 仓库。
2. 进入仓库 `Settings` -> `Pages`。
3. 选择 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/(root)`。
5. 保存后等待 GitHub Pages 生成公开链接。

## 内容说明

- `index.html` 是最终展示页面。
- 四个 `*.md` 文件用于记录每个项目的图片内容分类和文字分析。
- 四个同名文件夹保存对应项目图片资源。

## 说明

- 本页面不依赖打包工具或框架。
- 图片采用相对路径，适合 GitHub Pages 直接托管。
- 所有图片都支持点击后展开全图查看。
